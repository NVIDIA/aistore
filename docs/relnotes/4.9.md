# AIStore 4.9 Release Notes

AIStore **4.9** is a small patch release focused on space cleanup.
It follows 4.8 by about five weeks and is 100% backward compatible.

---

Space cleanup visits EC slices and metafiles in a given bucket, retaining each one only when its counterpart is present; both checks read the bucket's EC properties.
The bucket is now properly initialized before the traversal.

* [7b2fe2d16](https://github.com/NVIDIA/aistore/commit/7b2fe2d16): space/cleanup: fix nil-deref on EC content types (cherry-picked from [f45b936d7](https://github.com/NVIDIA/aistore/commit/f45b936d7))
