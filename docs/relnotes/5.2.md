# AIStore v5.2 Release Notes

<a name="upgrade-notes"></a>
## Upgrade Notes

### Placement metadata requires completing the upgrade

Complete the upgrade on every proxy and target before assigning target placement
weights or setting bucket placement overrides. Older nodes cannot decode the new
`placement` sections in cluster maps (Smap) and bucket metadata (BMD).

During a rolling upgrade, leave target weights unset and bucket placement overrides
omitted. Unweighted Smaps retain the pre-5.2 wire format and uniform HRW placement;
default bucket properties also omit the new placement section.

Assigning target weights requires all nodes to run the same AIS software version as
the primary. The weight-update API returns HTTP 409 while the primary has recorded a
software-version mismatch. Clearing all target weights remains allowed. A pre-5.2
node cannot participate in a cluster whose Smap carries weights, including equal
weights that produce uniform placement.

The current version check uses primary-local join records, which are incomplete
after a primary change. Verify every node's software version before assigning
weights, including after primary reelection. See [Placement weights](../placement.md)
for the current implementation status and compatibility constraints.
